# raw icmp

شبیه ساز حمله ddos با پروتکل icmp

**[Click here to view the English documentation](README.md)**


مسئولیت استفاده نادرست از کد به عهده شخص اجرا کننده کد است، این کد صرفا برای یادگیری نحوه سوکت نویسی icmp و برنامه نویسی همروندی نوشته و انتشار می‌یابد

## نصب و کامپایل

### 1. بررسی پیش‌نیازها

ابتدا اسکریپت `configure` را اجرا کنید تا از نصب بودن پیش‌نیازهای موردنیاز برای کامپایل این پروژه اطمینان حاصل شود.

```bash
chmod +x ./configur
./configure
```

اگر خروجی برنامه `OK` بود، می‌توانید به مرحله بعد بروید.

در غیر این صورت، یکی از پیش‌نیازها (مانند کامپایلر **GCC** یا پشتیبانی از **POSIX Threads (pthread)**) روی سیستم شما موجود نیست یا به‌درستی نصب نشده است. پس از رفع مشکل، این مرحله را دوباره اجرا کنید.

### 2. کامپایل

برای ساخت فایل اجرایی، دستور زیر را اجرا کنید:

```bash
make
```

### 3. نصب برنامه

برای نصب برنامه در مسیر اجرایی سیستم (PATH)، دستور زیر را اجرا کنید:

```bash
sudo make install
```

پس از نصب، می‌توانید برنامه را از هر مسیری در سیستم اجرا کنید

## Usage

جهت استفاده از برنامه پارامترهای زیر را به برنامه دهید:

### target_ip


آدرس آیپی مقصد (هدف) 


### duration_in_minutes


زمان اجرای حمله 


### thread_count


تعداد نخ های درگیر
(در این برنامه هر نخ به صورت جداگانه شروع به ارسال بسته‌های icmp  به سمت آیپی مقصد ارسال می‌کند.)
