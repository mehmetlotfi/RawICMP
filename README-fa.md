# dos project

شبیه ساز حمله dos با پروتکل های مختلف

**[Click here to view the English documentation](README.md)**


مسئولیت استفاده نادرست از کد به عهده شخص اجرا کننده کد است، این کد صرفا برای یادگیری نحوه سوکت نویسی و برنامه نویسی همروندی نوشته و انتشار می‌یابد
