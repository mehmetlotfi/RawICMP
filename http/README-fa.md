# http dos 

شبیه ساز حمله ddos با پروتکل http

**[Click here to view the English documentation](README.md)**


مسئولیت استفاده نادرست از کد به عهده شخص اجرا کننده کد است، این کد صرفا برای یادگیری نحوه سوکت نویسی http و برنامه نویسی همروندی نوشته و انتشار می‌یابد

## نصب و کامپایل

### 1. بررسی پیش‌نیازها

ابتدا اسکریپت `configure` را اجرا کنید تا از نصب بودن پیش‌نیازهای موردنیاز برای کامپایل این پروژه اطمینان حاصل شود.

```bash
chmod +x ./configure
./configure
```

اگر خروجی برنامه `OK` بود، می‌توانید به مرحله بعد بروید.

در غیر این صورت، یکی از پیش‌نیازها (مانند کامپایلر **GCC** یا پشتیبانی از **POSIX Threads (pthread)**) روی سیستم شما موجود نیست یا به‌درستی نصب نشده است. پس از رفع مشکل، این مرحله را دوباره اجرا کنید.

### 2. کامپایل

برای ساخت فایل اجرایی، دستور زیر را اجرا کنید:

```bash
make
```

### 3. (اختیاری) نصب برنامه

برای نصب برنامه در مسیر اجرایی سیستم (PATH)، دستور زیر را اجرا کنید:

```bash
sudo make install
```

پس از نصب، می‌توانید برنامه را از هر مسیری در سیستم اجرا کنید

## Usage

جهت استفاده از برنامه پارامترهای زیر را به برنامه دهید:

### thread_count


این آرگومان مشخص می‌کند که چند نخ به صورت همزمان مشغول ارسال بسته GET به سمت وب‌سرور هدف باشند.
(هرچه تعداد بیشتر = قدرت تخریب بیشتر برنامه به شرط داشتن منابع سخت‌افزاری کافی)



### host | ip


این آرگومان آدرس وب‌سرور مقصد را مشخص می‌کند، هم می‌توانید به این فیلد آیپی بدهید، هم دامنه؛
اگر دامنه باشد، از طریق DNS پیشفرض ست شده روی سیستم آدرس آیپی‌ آن را پیدا می‌کند و اگر هم آیپی بدهید، که فبها!.



### port


تاین آرگومان مشخص می‌کند، کدام پورت وب‌سرور (که آدرس آن را در آرگومان دوم داده‌اید) مشغول به استراق ترافیک HTTP است. تا روی آن پورت حمله را آغاز کند. مقدار پیشفرض این پورت برای HTTP پورت 80 و برای HTTPS پورت 443 است.


### مثال

برای نمونه می‌توانید در دستگاه خودتان 2 ترمینال (پوسته) مختلف اجرا کنید، در ترمینال اول دستور زیر را اجرا کنید:

```bash
python3 -m http.server
```

این دستور از دایرکتوری جاری به بعد روی پورت 8000 روی تمامی درگاه (interface)‌های سیستم‌تان یک وبسایت directory lister سرو می‌کند.
روی ترمینال بعدی‌تان برنامه‌ای که کامپایل کردید، روی (127.0.0.1:8000) حمله را با تناسب مناسبی از تخصیص نخ‌ها به برنامه، آغاز کنید و توسط یک مانیتورکننده منابع سیستم، منابع سیستم‌تان را مشاهده کنید.

### توجه

توجه: در هر موقع از کار که قصد منصرف کردن حمله را داشتید، می‌توانید اینکار را با ارسال سیگنال ```SIGINT``` به برنامه، برنامه را متوقف کنید. می‌توانید سیگنال مذکور را با فشردن کلید‌های ترکیبی ```Ctrl+C``` روی برنامه، به برنامه ارسال کنید.
